# Паттерн "Фабричный метод" (Factory Method)

## Описание

Паттерн "Фабричный метод" (или Factory Method) используется для создания объектов без указания точного класса создаваемого объекта. Этот паттерн позволяет классам делегировать создание объектов подклассам, что упрощает добавление новых типов объектов.

## Структура

### Классы

- **Product**: Базовый абстрактный класс или интерфейс, определяющий интерфейс для создаваемых объектов.
- **ConcreteProduct**: Конкретный класс, реализующий интерфейс Product. Это классы, экземпляры которых будут создаваться фабричным методом.
- **Creator**: Базовый абстрактный класс, определяющий фабричный метод factory_method. Этот метод возвращает объекты типа Product.
- **ConcreteCreator**: Конкретный класс, реализующий фабричный метод для создания объектов конкретного типа.

## Пример использования
В этом примере у нас есть две конкретные фабрики: CroissantFactory и MuffinFactory. Каждая из этих фабрик создает конкретные виды пирожных, такие как Croissant и Muffin. Функция order_pastry принимает фабрику, создаёт пирожное с её помощью и выполняет методы подготовки, выпекания и упаковки. Это демонстрирует, как можно использовать фабричный метод для создания различных объектов без указания их конкретных классов.
