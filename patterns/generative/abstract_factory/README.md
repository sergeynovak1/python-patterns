# Паттерн "Абстрактная фабрика" (Abstract Factory)

## Описание

Паттерн "Абстрактная фабрика" (или Abstract Factory) предоставляет интерфейс для создания семейств связанных или зависимых объектов без указания их конкретных классов. Этот паттерн позволяет клиенту создавать объекты, которые являются частью единой семейства, гарантируя, что эти объекты будут совместимы между собой.

## Структура

### Классы

- **AbstractFactory**: Базовый абстрактный класс или интерфейс, определяющий методы для создания продуктов.
- **ConcreteFactory**: Конкретный класс, реализующий интерфейс AbstractFactory. Этот класс создает конкретные продукты.
- **AbstractProductA** и **AbstractProductB**: Базовые абстрактные классы или интерфейсы для различных видов продуктов.
- **ConcreteProductA** и **ConcreteProductB**: Конкретные классы, реализующие интерфейсы AbstractProductA и AbstractProductB. Эти классы представляют конкретные продукты, создаваемые конкретной фабрикой.

## Пример использования
В этом примере у нас есть две конкретные фабрики: ModernFurnitureFactory и VictorianFurnitureFactory. Каждая из этих фабрик создает конкретные виды мебели, такие как стулья и столы в соответствующем стиле. Функция client_code принимает фабрику, создает стул и стол с её помощью, и выполняет методы, демонстрируя, как можно использовать абстрактную фабрику для создания семейства связанных объектов без указания их конкретных классов.
