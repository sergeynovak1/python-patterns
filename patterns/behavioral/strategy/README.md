# Паттерн "Стратегия" (Strategy)

## Описание

Паттерн "Стратегия" (или Strategy) используется для определения семейства алгоритмов, инкапсуляции каждого из них и обеспечения их взаимозаменяемости. Этот паттерн позволяет выбирать алгоритм поведения объекта во время выполнения.

## Структура

### Классы

- **PaymentStrategy**: Базовый абстрактный класс, который определяет общий интерфейс для всех стратегий оплаты. Метод pay в этом классе должен быть реализован всеми конкретными стратегиями.
- **CreditCardPayment**: Конкретная стратегия оплаты, использующая кредитную карту. Реализует метод pay, который выводит сообщение об оплате кредитной картой.
- **PayPalPayment**: Конкретная стратегия оплаты, использующая PayPal. Реализует метод pay, который выводит сообщение об оплате через PayPal.
- **ShoppingCart**: Класс корзины для покупок, который использует стратегии оплаты. Содержит методы для установки стратегии оплаты и выполнения операции оплаты.

## Пример использования

В приведенном ниже примере создается корзина для покупок, которая может использовать разные стратегии оплаты. Сначала устанавливается стратегия оплаты с помощью кредитной карты и выполняется операция оплаты. Затем стратегия изменяется на оплату через PayPal, и снова выполняется операция оплаты.
