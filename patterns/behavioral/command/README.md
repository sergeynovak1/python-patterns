# Паттерн "Команда" (Command)

## Описание

Паттерн "Команда" (или Command) используется для инкапсуляции запроса в объект, что позволяет параметризовать объекты другими запросами, ставить запросы в очередь или вести их журнал. Этот паттерн позволяет отделить объект, инициирующий операцию, от объекта, который знает, как выполнить эту операцию.

## Структура

### Классы

- **Command**: Базовый абстрактный класс или интерфейс, определяющий метод execute и содержащий атрибут is_complete.
- **ConcreteCommand**: Конкретный класс команды, реализующий интерфейс Command. Этот класс связывает определённое действие с получателем.
- **Receiver**: Класс, который выполняет действие, связанное с командой.
- **Invoker**: Класс, который инициирует выполнение команды.
- **TransactionManager**: Класс, управляющий выполнением команд и отслеживающий их состояние.
- **Client**: Класс, который создает объекты команд и связывает их с получателями.

## Пример использования
В этом примере мы создали транзакционный менеджер (TransactionManager), который управляет выполнением команд и отслеживает их статус с помощью атрибута is_complete. Команды включения и выключения света (LightOnCommand, LightOffCommand) и кондиционера (ACOnCommand, ACOffCommand) реализуют интерфейс Command и устанавливают атрибут is_complete в True после успешного выполнения. Транзакционный менеджер добавляет команды в список, выполняет их и проверяет, все ли команды выполнены успешно, используя метод get_transaction_status.
