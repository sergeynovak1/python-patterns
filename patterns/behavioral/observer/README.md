# Паттерн "Наблюдатель" (Observer)

## Описание

Паттерн "Наблюдатель" (или Observer) используется для создания механизма подписки, который позволяет одним объектам следить и реагировать на изменения состояния других объектов. Этот паттерн особенно полезен при построении системы с одним источником данных и несколькими заинтересованными подписчиками.

## Структура

### Классы

- **Subject**: Интерфейс или абстрактный класс, представляющий объект, за состоянием которого следят. Определяет методы для добавления, удаления и уведомления наблюдателей.
- **ConcreteSubject**: Конкретный объект, реализующий интерфейс Subject. Хранит состояние и уведомляет наблюдателей об изменениях.
- **Observer**: Интерфейс или абстрактный класс для всех наблюдателей. Определяет метод update, который вызывается при изменении состояния объекта Subject.
- **ConcreteObserver**: Конкретный наблюдатель, реализующий интерфейс Observer. Получает обновления от объекта Subject и выполняет соответствующие действия.

## Пример использования
В приведенном ниже примере создается объект ConcreteSubject, который поддерживает список наблюдателей. Когда состояние объекта изменяется, все наблюдатели получают уведомления и выполняют свои действия.
