# Паттерн "Шаблонный метод" (Template Method)

## Описание

Паттерн "Шаблонный метод" (или Template Method) определяет скелет алгоритма в методе базового класса, позволяя подклассам переопределять определенные шаги алгоритма без изменения его структуры. Это позволяет повторно использовать общую часть алгоритма и давать возможность подклассам изменять отдельные этапы, если это необходимо.

## Структура

### Классы

- **AbstractClass**: Абстрактный класс, содержащий шаблонный метод, который определяет последовательность шагов алгоритма. Реализация некоторых шагов может быть делегирована абстрактным методам, которые должны быть реализованы в подклассах.
- **ConcreteClass**: Конкретный класс, реализующий абстрактные методы, определенные в AbstractClass.

## Пример использования
В этом примере у нас есть абстрактный класс Beverage, который определяет шаблонный метод prepare_recipe, содержащий последовательность шагов для приготовления напитка. Общие шаги, такие как boil_water и pour_in_cup, реализованы в абстрактном классе. Абстрактные методы brew и add_condiments делегируют выполнение конкретных шагов подклассам Tea и Coffee. Клиентский код создает объекты чая и кофе и вызывает метод prepare_recipe, который выполняет общий алгоритм, переопределяя шаги в зависимости от типа напитка.
