# Паттерн "Итератор" (Iterator)

## Описание

Паттерн "Итератор" (или Iterator) используется для последовательного доступа к элементам коллекции без раскрытия ее внутреннего представления. Этот паттерн позволяет клиентскому коду перебирать элементы коллекции, не завися от конкретной реализации этой коллекции.

## Структура

### Классы

- **Iterator**: Интерфейс, определяющий методы для перебора элементов коллекции (например, next и has_next).
- **ConcreteIterator**: Конкретная реализация интерфейса Iterator, которая предоставляет конкретные способы перебора элементов.
- **Iterable**: Интерфейс, определяющий метод для создания итератора (например, create_iterator).
- **ConcreteIterable**: Конкретная реализация интерфейса Iterable, которая возвращает экземпляр конкретного итератора.

## Пример использования
В этом примере у нас есть класс Bookshelf, представляющий коллекцию книг, и класс BookIterator, реализующий итератор для перебора этих книг. Интерфейсы Iterator и Iterable определяют методы, которые должны быть реализованы в конкретных итераторах и итерируемых коллекциях соответственно. Клиентский код создает книжную полку, добавляет в нее книги и использует итератор для последовательного доступа к этим книгам. Это позволяет абстрагироваться от конкретной реализации коллекции и использовать единый интерфейс для доступа к ее элементам.
