# Паттерн "Декоратор" (Decorator)

## Описание

Паттерн "Декоратор" (или Decorator) используется для динамического добавления новых поведений объектам, оборачивая их в объекты-декораторы. Этот паттерн предоставляет гибкую альтернативу субклассированию для расширения функциональности.

## Структура

### Классы

- **Component**: Базовый абстрактный класс, определяющий интерфейс для всех объектов, которые могут быть декорированы.
- **ConcreteComponent**: Конкретный компонент, который может быть декорирован. Реализует интерфейс Component.
- **Decorator**: Абстрактный класс декоратора, который реализует интерфейс Component и содержит ссылку на компонент. Реализует методы интерфейса, делегируя их вызовы вложенному компоненту.
- **ConcreteDecorator**: Конкретный декоратор, который добавляет новое поведение к компоненту. Реализует методы интерфейса, добавляя новое поведение перед или после вызова метода вложенного компонента.

## Пример использования
Представьте себе кафе, где можно заказать кофе, а затем добавить к нему различные добавки, такие как молоко, сахар или сироп. Кофе является базовым компонентом, а добавки — декораторами, которые добавляют дополнительный вкус.
