# Паттерн "Адаптер" (Adapter)

## Описание

Паттерн "Адаптер" (или Adapter) используется для преобразования интерфейса одного класса в интерфейс, который ожидает клиент. Этот паттерн позволяет классам с несовместимыми интерфейсами работать вместе. Адаптер выступает как обертка вокруг другого объекта и переводит его интерфейс в интерфейс, понятный клиенту.

## Структура

### Классы

- **Target**: Целевой интерфейс, с которым работает клиент.
- **Adapter**: Класс адаптера, реализующий целевой интерфейс и преобразующий запросы в формат, понятный адаптируемому объекту.
- **Adaptee**: Класс, который необходимо адаптировать.
- **Client**: Класс, который использует целевой интерфейс.

## Пример использования
В этом примере у нас есть старая система отчетности OldReportSystem, которая генерирует отчеты в виде строк. Мы создали адаптер ReportAdapter, который реализует целевой интерфейс Report и преобразует данные из старого формата в новый, разбивая строку отчета на заголовок и содержимое. Функция клиентского кода client_code использует объект ReportAdapter как если бы это был объект, реализующий целевой интерфейс Report.
