# Паттерн "Фасад" (Facade)

## Описание

Паттерн "Фасад" (или Facade) используется для предоставления унифицированного интерфейса к набору интерфейсов в подсистеме. Фасад определяет интерфейс более высокого уровня, который упрощает использование подсистемы. Этот паттерн помогает скрыть сложность системы и предоставляет клиенту простой способ взаимодействия с ней.

## Структура

### Классы

- **Facade**: Класс, предоставляющий унифицированный интерфейс для работы с подсистемами.
- **Subsystem Classes**: Классы подсистем, выполняющие фактическую работу. Они не имеют прямой зависимости от фасада и могут быть использованы самостоятельно.
- **Client**: Класс, который использует фасад для взаимодействия с подсистемами.

# Пример использования
В этом примере у нас есть три подсистемы: телевизор (TV), аудиосистема (SoundSystem) и проигрыватель дисков (DVDPlayer). Фасад HomeTheaterFacade предоставляет простой интерфейс для управления всеми этими устройствами. Клиентский код может использовать методы watch_movie и end_movie, чтобы включить и настроить все устройства для просмотра фильма, а затем выключить их после просмотра. Это упрощает взаимодействие с комплексной системой домашнего кинотеатра, скрывая детали реализации и предоставляя унифицированный интерфейс.
